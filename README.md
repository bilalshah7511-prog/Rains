# Rains — Checkout Skin Demo

PayPhi-style checkout drawer skin for [Rains](https://www.us.rains.com) (Outdoor Voices pattern).

## Font

**Europa Grotesque Bold only** (`public/fonts/EuropaGroNr2SH-Bol.otf`). No other typefaces.

## Run

```bash
npm install
npm run dev
```
